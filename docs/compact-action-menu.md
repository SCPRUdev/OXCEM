# Компактное меню действий и навыков

Пункт меню имеет ширину 200 и высоту 30 логических пикселей. Используется
`FONT_SMALL`: первая строка содержит название, вторая — точность и стоимость
действия. Размеры относятся к внутреннему разрешению игры, до масштабирования.

Для левой руки сохранено прежнее горизонтальное положение меню. Для правой
руки оно зеркально относительно центра боевой панели; меню навыков расположено
по центру между ними. При ширине панели 320 px левые края меню находятся на
24, 96 и 60 px соответственно относительно левого края панели.

Меню действий предмета и меню навыков используют динамический список.
При базовом разрешении 320×200 одновременно видны до шести пунктов;
при большей логической высоте экрана помещается больше. Длинные списки
прокручиваются колесом мыши и клавишами Page Up / Page Down. Под списком
показывается диапазон видимых пунктов и общее количество. Сохранён прежний
порядок заполнения снизу вверх: прокрутка вверх открывает следующие пункты.

Существующие горячие клавиши действуют также для пунктов за пределами
видимой области. Меню навыков больше не отбрасывает доступные навыки после
исчерпания пяти горячих клавиш: остальные доступны мышью.

Это изменение интерфейса. Набор типов действий предмета и их правила
выполнения остались прежними. Для нескольких разновидностей рукопашной атаки,
очередей или медицинских операций ещё требуется расширить описание действий
в рулсетах и обработку выбранного варианта. Новых реквизитов рулсетов на этом
этапе нет. Длинные названия следует проверить на помещаемость в первой строке.

## Настройка цветов в рулсете

Оба меню используют существующий элемент `actionMenu` интерфейса `battlescape`.
В OpenSCP блок явно добавлен в `Ruleset/Interfaces.rul`:

```yaml
interfaces:
  - type: battlescape
    elements:
      - id: actionMenu
        color: -1
        border: 3
        color2: 14
```

| Параметр | Назначение | Базовое значение X-COM 1 |
| --- | --- | --- |
| `color` | Цвет названия, точности, стоимости и счётчика страниц | `-1` |
| `border` | Базовый цвет рамки пункта | `3` |
| `color2` | Цвет фона пункта | `14` |

Цвета задаются индексами текущей боевой палитры, а не RGB. Значение `-1`
для текста преобразуется в индекс `255`. Рамка и текст рисуются с повышенным
контрастом и используют дополнительные оттенки относительно заданного цвета.
При наведении цвет фона уменьшается на 3; при `TFTDMode: true` — на 12.
Для фона следует выбирать индекс, допускающий такое смещение без перехода
на нежелательную цветовую полку.

Настройки общие для меню обеих рук и навыков. При отсутствии переопределения
используются значения базового рулсета. После редактирования перезапустите игру,
чтобы загрузить рулсеты заново. Пересборка движка не требуется.

## Проверка в игре

1. Открыть меню огнестрельного оружия, холодного оружия, гранаты и аптечки;
   проверить названия, точность, стоимость, выбор мышью и закрытие правой кнопкой.
2. Проверить привычные горячие клавиши выбора действий.
3. Открыть меню навыков солдата и проверить выбор части тела для прицеливания.
4. На солдате с десятью или более доступными навыками проверить прокрутку,
   выбор последнего навыка и горячие клавиши после прокрутки.
5. Проверить меню при разных настройках масштаба боевого экрана.

Проверка сборкой: MSVC v143, Win32 Release. Визуальная проверка в игре
после изменения интерфейса остаётся необходимой.
